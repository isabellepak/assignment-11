# Module 11: Data Visualization – SunCoast Retail Visual Analysis

## Files Included
module11-assignment.py

## What I Practiced
In this assignment, I practiced applying data visualization techniques to analyze business data using Python. I used libraries such as pandas, numpy, and matplotlib to create a variety of charts that illustrate trends, comparisons, and relationships within the data. I also developed skills in selecting appropriate visualization types and presenting data in a clear, meaningful way.

## Key Concepts
Time series visualization (sales trends over time)  
Categorical comparison (product performance by location)  
Relationship analysis (advertising spend vs. sales)  
Distribution analysis (customer demographics and purchasing behavior)  
Data visualization using matplotlib  

## Summary
This project demonstrates how data visualization can be used to communicate business insights effectively. The visualizations highlight sales trends, customer patterns, and category performance, helping to support data-driven decision-making and identify areas for improvement.
